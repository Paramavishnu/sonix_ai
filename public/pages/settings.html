Settings

Appearance

Dark-first with light mode toggle. Respects prefers-reduced-motion.

Firebase

Frontend config is in window.__FIREBASE_CONFIG__. If not set, demo-local fallback is active (no quotas used).

FIREBASE_PROJECT_ID=demo-sonixai
FIREBASE_API_KEY=demo
# Set real values in .env and inject via server or frontend config

Free quotas apply when Firebase is configured. App never claims unlimited cloud.

Local Assets

Music: public/assets/music/*.mp3 (Calm, Cinematic, etc.) SFX: public/assets/sfx/*.mp3. Replace with your licensed files.

Optional AI

Leave OPTIONAL_AI_IMAGE_API_KEY and OPTIONAL_TRANSLATION_API_KEY empty to stay 100% free. Core always works.
